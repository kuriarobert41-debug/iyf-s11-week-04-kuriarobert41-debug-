### Lesson 7: JavaScript Basics

#### Task 7.1: Variables & Setup ✅
- Variable declarations with `let`, `const`
- Data types and `typeof` operator
- Console logging with descriptive messages

#### Task 7.2: Data Types & Operators ✅
- Number operations (arithmetic, exponentiation, increment/decrement)
- String operations (concatenation, template literals, string methods)
- Comparison and logical operators
- Age calculations (days, hours, year turning 100)

#### Task 7.3: Functions ✅
- Function declarations, expressions, and arrow functions
- Built functions:
  - `calculateArea(width, height)` - Rectangle area
  - `celsiusToFahrenheit(celsius)` - Temperature conversion
  - `isEven(number)` - Check if number is even
  - `getInitials(fullName)` - Extract initials from name
  - `reverseString(str)` - Reverse a string

#### Task 7.4: Control Flow ✅
- If/Else statements with `getGrade(score)` function
- Switch statements with `getDayName(dayNumber)` function
- For loops, while loops, and for...of loops
- Programs:
  - Print numbers 1-100
  - Print even numbers 1-50
  - FizzBuzz implementation
  - Triangle of stars pattern

#### Mini-Project: Calculator 🔴 ✅
- Functions: `add()`, `subtract()`, `multiply()`, `divide()`
- Main `calculate(num1, operator, num2)` function
- Supports operators: `+`, `-`, `*`, `/`, `%`, `**`
- Division by zero error handling

### Lesson 8: Arrays & Objects

#### Task 8.1: Arrays ✅
- Array creation and manipulation (push, pop, shift, unshift)
- Array methods:
  - `map()` - Transform elements
  - `filter()` - Keep matching elements
  - `find()` - Get first matching element
  - `reduce()` - Combine all elements
  - `includes()` - Check existence
- Practical exercises on array manipulation

#### Task 8.2: Objects ✅
- Object creation with properties and nested objects
- Dot notation and bracket notation access
- Object methods (function properties)
- Object iteration:
  - `Object.keys()` - Get all keys
  - `Object.values()` - Get all values
  - `Object.entries()` - Get key-value pairs

#### Task 8.3: Array of Objects ✅
- Working with student data (array of objects)
- Using array methods on objects:
  - Map names
  - Filter by grade
  - Find specific students
  - Calculate averages
  - Sort by grade

#### Mini-Project: Student Grade Tracker 🔴 ✅
Complete grade management system with methods:
- `addStudent(name, grades)` - Add new student
- `getStudent(name)` - Retrieve student
- `getStudentAverage(name)` - Calculate average
- `getSubjectAverage(subject)` - Class average for subject
- `getTopStudent()` - Find highest performer
- `getStrugglingStudents()` - Find students with average < 70
- `getLetterGrade(score)` - Convert score to letter grade
- `generateReportCard(name)` - Format student report
